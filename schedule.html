My device still shows old information

First open an outdated event and check which calendar it belongs to. Use one CHOSEN calendar to avoid duplicates.

  • Google: on a computer, use Other calendars + → From URL and paste the calendar link above. Import & Export creates a separate copy that will not receive changes.
  • Apple: add the link as a subscribed calendar. On a Mac, select the subscription, choose Get Info and set Auto-refresh; use View → Refresh Calendars to check now.
  • Old copies: if an event was imported or copied into your personal calendar, it will stay separate. Hide the old CHOSEN calendar while checking the current subscription. Remove only confirmed old CHOSEN copies, keeping your other events.

For same-day changes and your individual call, use My Calls on the Hub. Do not assume everyone is called for the full shared calendar window.
